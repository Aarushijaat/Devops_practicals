**# Practical 3 - Docker Image Update and Push**



**## Steps Performed:**



**1. Pulled base image (ubuntu/python:alpine)**

**2. Ran container**

**3. Modified container**

**4. Committed container as new image**

**5. Tagged image with Docker Hub username**

**6. Logged into Docker Hub**

**7. Pushed image**

**8. Removed local image**

**9. Pulled image again**

**10. Verified changes**

**11. Compared image size**
